Settings

Authorized reviewers

Comma-separated names allowed to approve products, accept proposals, waive blockers, approve rules and give final approval. Leave empty to allow any named reviewer (the name is always recorded).

Cataloging assistant (optional)

Uses Claude through the Anthropic API (credentials from ANTHROPIC_API_KEY or an ant auth login profile). It is asked only for judgment calls — choosing among approved categories, finding an equivalent approved dropdown value, drafting descriptions from vendor evidence and describing images — and every answer is checked against the approved lists and marked “Cataloging judgment” for review. Requests use server-side model fallbacks, so a declined request can be retried on another model. Product data is sent to the API when this is on.

Mumzworld.com reference lookup

When used, the search page is fetched and any listing links found are recorded as unreviewed candidates. If the site cannot be reached, that is recorded; nothing is claimed as inspected.
